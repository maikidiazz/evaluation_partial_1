¿De qué trata?

GameTask es una plataforma que conecta a personas que necesitan ayuda para completar actividades dentro de videojuegos con jugadores capaces de realizar esos servicios.

El cliente paga por el servicio y el jugador recibe una parte del pago. La plataforma obtiene ingresos mediante una comisión por cada servicio realizado.

⚙️

¿Cómo funciona?

1. 🎮 El cliente solicita un servicio.

2. 🧑‍💻 Un jugador acepta la solicitud.

3. 🏆 El jugador realiza la actividad solicitada.

4. 💰 Se realiza el pago y la plataforma obtiene una comisión.
